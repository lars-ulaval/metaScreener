# wave17_arms — the wave-17 criteria-experiment arms: design, dry run and the

# THE EXPERIMENT: eight authored criteria for a respiratory-sinus-arrhythmia
# review, plus nine deliberate variations on them, each screened through the
# product's own EH/IH/EL/IL engines. Per-criterion intents were REGISTERED

# the design rather than describe it.
#
# DATE:      2026-08-16 (arms 17a-17d) and 2026-08-17 (h6, h9, h7 at 17e)
# BRANCH:    fix/wave-17e-freeze
# ENDPOINT:  http://localhost:11434/v1 (OPENAI_BASE_URL not set; store default)
# MODEL:     qwen2.5:7b, passed EXPLICITLY per stage for EL AND IL, never
#            store-resolved. live_preflight refuses to run unless
#            live.model.{EL,IL} are both set, because the GUI path has a
#            stage-to-app-level fallback (settings.py:411, effective()) that
#            would silently resolve IL to a different model.
# WINDOW:    4096 both stages     TRUNC: 1500     TEMP: 0.0
# BATCH:     5 both stages on every arm EXCEPT h9_batch1, which is 1 — that is
#            the arm's only variable and F-247 is what it measured.
# PROMPTS:   EL_v3_nullquote / IL_v3_nullquote
# POLICY:    exclusion_policy=flag_only on every arm. NOTHING WAS REMOVED
#            ANYWHERE: OUT=0 in all twenty stage summaries.
# CACHE:     OFF in every arm (use_cache=false, enforced in three places).
#            Required, not incidental: h0 and h9 differ only in batch size and
#            the F-101 cache key is blind to batch size, so a live cache would
#            have silently collapsed the two arms this freeze exists to compare.
# SHAPE:     request_shape=json_schema on every call of every arm; no F-107
#            unconstrained fallback fired anywhere.

# CORPUS:    samples/20260816_1841_rsaAggregate.csv, 463 records, sha256

# crit_impacts.json IS A DERIVATION, NOT A CAPTURE, and it exists because of

# LINE ENDINGS: dryrun_v1/** and live_v1/** are pinned `binary` in

# digest is a promise about bytes, so that had to be settled first. Pinning
# changed no committed byte: it is a metadata change only. The nine top-level
# files stay `text eol=crlf` deliberately, because experiment_spec.json records
